## 📋 Project Overview

**Socio** is a fully-featured social media platform developed using **ASP.NET Core MVC**, **Razor Pages**, and **Entity Framework Core**.  
It demonstrates modern web development practices including authentication, real-time interactions, clean architecture, and responsive UI.

## ✨ Features

### 👤 User Features
- Secure Sign-Up, Login & Logout
- View and edit personal profiles
- Upload profile picture & bio
- Create, edit and delete posts
- Like / Dislike posts
- Comment on posts
- Delete own comments
- Real-time comment notifications
- View single post with interactions
- Centralized feed
- Search for users
- Visit other user profiles

### 🛠️ Admin Features

#### 📊 Dashboard & Analytics
- Platform statistics overview
- Activity graphs (Users, Posts, Likes, Comments)
- Growth comparison over time

#### 👥 User Management
- View all users
- Search users with filters
- View detailed profiles
- Manage permissions
- Ban / Unban users

#### 🛡️ Content Moderation
- View comments by user
- Monitor user activity
- Hide / Unhide comments
